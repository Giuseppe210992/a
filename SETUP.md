# B&B Tracker - Setup & Deployment Guide\n\n## Panoramica Progetto\n\n**B&B Tracker PRO** è una piattaforma web completa per la gestione dei check-in alberghieri multi-struttura con conformità alle normative italiane (Alloggiati Web, ISTAT Ross1000).\n\n### Caratteristiche Principali\n\n1. **Gestione Multi-Struttura**: Ogni hotel ha profilo, dati e storico separati\n2. **OCR Avanzato**: Estrazione dati da documenti (carta d'identità, passaporto, patente) tramite LLM vision\n3. **Firma Digitale GDPR**: Canvas per la firma del cliente con salvataggio su cloud storage\n4. **Conformità Normativa**: Integrazione SOAP Alloggiati Web e generazione file ISTAT Ross1000\n5. **Reportistica**: Report mensili in CSV e PDF con statistiche\n6. **Notifiche Automatiche**: Alert all'admin della struttura al completamento di ogni check-in\n7. **Storage Cloud**: Immagini documenti e firme archiviate su cloud con riferimento nel database\n\n## Architettura Tecnica\n\n### Stack Tecnologico\n\n- **Frontend**: React 19 + Tailwind CSS 4 + shadcn/ui\n- **Backend**: Express 4 + tRPC 11 + Node.js\n- **Database**: MySQL/TiDB (Manus managed)\n- **Storage**: Cloud Storage (Manus S3-compatible)\n- **LLM**: Integrazione nativa Manus per OCR e validazione\n- **PDF**: FPDF per generazione ricevute e report\n\n### Struttura Database\n\n```\nusers (autenticazione + ruoli)\nhotels (multi-tenancy)\nguests (ospiti)\ncheckins (check-in)\ncheckinGuests (ospiti aggiuntivi)\nsignatures (firme GDPR)\ndocuments (PDF, XML, CSV generati)\nnotifications (log notifiche)\n```\n\n## Setup Locale\n\n### Prerequisiti\n\n- Node.js 18+\n- pnpm 10+\n- Accesso a database MySQL (fornito da Manus)\n- Accesso a cloud storage (fornito da Manus)\n\n### Installazione\n\n```bash\ncd /home/ubuntu/bb-tracker\npnpm install\n```\n\n### Variabili d'Ambiente\n\nLe seguenti variabili sono automaticamente iniettate da Manus:\n\n```\nDATABASE_URL=mysql://user:pass@host/db\nJWT_SECRET=<generated>\nVITE_APP_ID=<manus-app-id>\nOAUTH_SERVER_URL=https://api.manus.im\nVITE_OAUTH_PORTAL_URL=https://login.manus.im\nBUILT_IN_FORGE_API_URL=<manus-api-url>\nBUILT_IN_FORGE_API_KEY=<manus-api-key>\nVITE_FRONTEND_FORGE_API_URL=<manus-api-url>\nVITE_FRONTEND_FORGE_API_KEY=<manus-api-key>\n```\n\n### Avvio Sviluppo\n\n```bash\npnpm dev\n```\n\nL'applicazione sarà disponibile su `http://localhost:3000`\n\n### Build Produzione\n\n```bash\npnpm build\npnpm start\n```\n\n## Flusso Operativo\n\n### 1. Registrazione Struttura\n\n1. Admin struttura accede con OAuth Manus\n2. Crea profilo hotel (nome, indirizzo, contatti)\n3. Configura parametri SOAP (WSKEY Alloggiati, Codice Ross1000)\n4. Aggiunge operatori con ruolo \"operator\"\n\n### 2. Nuovo Check-in\n\n1. Operatore avvia nuovo check-in\n2. Acquisisce foto documento principale (OCR estrae dati)\n3. Firma digitale GDPR su canvas\n4. Seleziona numero ospiti\n5. Acquisisce documenti ospiti aggiuntivi\n6. Sistema valida dati e genera PDF ricevuta\n7. Notifica automatica inviata all'admin\n8. Predisposizione invio Alloggiati Web e Ross1000\n\n### 3. Reportistica\n\n- Report mensile scaricabile in CSV e PDF\n- Statistiche: numero check-in, importo totale, media\n- Filtri per data, ospite, importo\n\n## Moduli Principali\n\n### Backend\n\n#### `server/ocr.ts`\n- `extractDocumentData()`: Estrae dati da documento tramite LLM vision\n- `validateDocumentAgainstBooking()`: Valida documento vs prenotazione\n- `saveDocumentImage()`: Salva immagine su cloud storage\n\n#### `server/pdf-generator.ts`\n- `generateCheckinPDF()`: Genera ricevuta check-in con firma\n- `generateMonthlyReportPDF()`: Genera report mensile\n\n#### `server/compliance.ts`\n- `generateAlloggiatiXML()`: Genera XML per Alloggiati Web\n- `generateRoss1000CSV()`: Genera file ISTAT Ross1000\n- `validateComplianceData()`: Valida conformità normativa\n\n#### `server/db.ts`\n- Query helper per tutte le tabelle\n- Gestione multi-tenancy per hotel\n\n### Frontend\n\n#### Pagine Principali\n- `Home.tsx`: Dashboard con statistiche\n- `CheckinFlow.tsx`: Flusso acquisizione documento e firma\n- `Reports.tsx`: Visualizzazione e download report\n- `HotelSettings.tsx`: Configurazione struttura\n\n## Deploy su Oracle Cloud AMD\n\n### Prerequisiti Oracle Cloud\n\n1. Account Oracle Cloud Free Tier\n2. Istanza AMD (Always Free)\n3. Accesso SSH configurato\n\n### Deployment Steps\n\n```bash\n# 1. SSH nella VM Oracle\nssh ubuntu@<oracle-vm-ip>\n\n# 2. Installa Node.js e pnpm\ncurl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -\nsudo apt-get install -y nodejs\ncurl -fsSL https://get.pnpm.io/install.sh | sh -\n\n# 3. Clone repository\ngit clone <repo-url> /opt/bb-tracker\ncd /opt/bb-tracker\n\n# 4. Installa dipendenze\npnpm install\n\n# 5. Build produzione\npnpm build\n\n# 6. Setup PM2 per auto-restart\nsudo npm install -g pm2\npm2 start dist/index.js --name bb-tracker\npm2 startup\npm2 save\n\n# 7. Setup Nginx reverse proxy\nsudo apt-get install -y nginx\n# Configura /etc/nginx/sites-available/default per proxy a localhost:3000\n\n# 8. Setup SSL con Let's Encrypt\nsudo apt-get install -y certbot python3-certbot-nginx\nsudo certbot --nginx -d yourdomain.com\n```\n\n### Configurazione Firewall Oracle\n\n```bash\n# Apri porte 80 e 443\nsudo iptables -I INPUT -p tcp -m tcp --dport 80 -j ACCEPT\nsudo iptables -I INPUT -p tcp -m tcp --dport 443 -j ACCEPT\nsudo iptables-save | sudo tee /etc/iptables/rules.v4\n```\n\n## Testing\n\n```bash\n# Unit tests\npnpm test\n\n# Test OCR\npnpm test -- server/ocr.test.ts\n\n# Test compliance\npnpm test -- server/compliance.test.ts\n```\n\n## Monitoraggio\n\n### Log Files\n\n```bash\n# Dev server log\ncat .manus-logs/devserver.log\n\n# Browser console\ncat .manus-logs/browserConsole.log\n\n# Network requests\ncat .manus-logs/networkRequests.log\n```\n\n### Performance\n\n- OCR processing: ~2-5 secondi per documento\n- PDF generation: ~1-2 secondi\n- Alloggiati Web SOAP: ~3-5 secondi\n\n## Troubleshooting\n\n### OCR non estrae dati\n\n1. Verificare qualità immagine\n2. Controllare LLM response nel log\n3. Validare formato documento\n\n### Firma non salva\n\n1. Verificare cloud storage connectivity\n2. Controllare permessi storage\n3. Validare base64 encoding firma\n\n### Errore Alloggiati Web\n\n1. Verificare WSKEY configurato\n2. Controllare formato XML generato\n3. Validare dati ospiti obbligatori\n\n## Support & Documentazione\n\n- **API Documentation**: `/docs/api.md`\n- **User Guide**: `/docs/user-guide.md`\n- **Admin Guide**: `/docs/admin-guide.md`\n- **Architecture**: `/docs/architecture.md`\n\n## License\n\nMIT\n"
